Pint's Disenchant v1.2 - a destroy list for enchanters
(WoW Classic Era / Hardcore / Forever)

REQUIRES
  The Enchanting profession (to disenchant). Nothing else.
  Optional:  Auctionator - shows the auction value of Bind on Equip items in the list

INSTALL
  Unzip so the folder sits at:  World of Warcraft\_classic_era_\Interface\AddOns\PintsDisenchant
  Restart the game.

HOW TO USE
  /pd (or /disenchant), or the minimap button.

  - The window lists every item in your bags that can be disenchanted, lowest quality first.
  - Click "Disenchant next" - or press its keybind - to disenchant the next item. One click per item:
    the game requires a real click or key press for each disenchant.
    Set the keybind under Key Bindings > AddOns > Pint's Disenchant.
  - Or click any item in the list to disenchant that one.
  - Tick which qualities to include (Uncommon, Rare, Epic) and whether to include Bind on Equip items.
  - Items above your Enchanting skill are marked with the skill they need.
  - Right-click an item to ignore it. "Ignored" shows them again, and clicking one puts it back.
  - Items that can never be disenchanted are left out, and anything the game refuses twice is ignored for you.
  - Clicking too fast (while the last disenchant is still finishing) is skipped safely - just click again.
  - In combat the buttons pause and come back afterwards.

COMMANDS
  /pd         open or close the list
  /pd reset   move the window back to the middle of the screen
  /pd log     show the last items the game refused (for bug reports)
